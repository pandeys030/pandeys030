## 🩺 Retino
### `Explainable Diabetic Retinopathy Detection System`

An AI-powered system that detects the severity of diabetic retinopathy from retinal images and explains **why** the model made its prediction.

**⚡ Highlights**

- 🧠 Built a **5-class diabetic retinopathy classification model**
- 🔬 Used **EfficientNet-B0** with PyTorch
- 🔥 Implemented **Grad-CAM** to visualize regions influencing predictions
- 🌐 Built an interactive **Streamlit application**
- 📄 Added automated **PDF report generation**
- 💡 Provides prediction, confidence score, class probabilities and recommendations

**Tech Stack**

`Python` `PyTorch` `EfficientNet-B0` `timm` `Streamlit` `Grad-CAM`
